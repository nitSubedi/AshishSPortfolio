# Claude Code Instructions

## Git & Pushing

Always push using SSH:

```
git push origin main
```

The remote is configured as `git@github.com:nitSubedi/AshishSPortfolio.git`. Do not use HTTPS or tokens — SSH is set up and working.

## Workflow

After every code change, remind the user to run `npm run dev` and verify the result in the browser. Wait for explicit approval before pushing to GitHub.
